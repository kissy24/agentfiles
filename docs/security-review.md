## 残る制約

- 検査は、レビューした信頼できるチェックアウトで実行します。Pythonコード自体や許可手順まで改ざんされたチェックアウトを安全に実行するサンドボックスではありません。
- 導入元・導入先を他者が同時に書換可能な環境のディレクトリ差替え競合は防御対象外です。信頼できる管理下のディレクトリを使用します。途中失敗の自動ロールバックは提供しません。
- 秘密情報検査は、現在の追跡済み／非ignoreファイルへの7種類の正規表現です。Git履歴、ignore対象、独自形式、難読化・暗号化された秘密値は検出保証の対象外です。Gitleaks等の包括的な専用スキャナーは今回未使用です。
- AWFのMarkdownは権限を技術的に強制しません。本番操作・秘密情報送信・承認は対象環境の実効的制御と組み合わせる必要があります。独立したCodexセッションの実運用試験も未実施です。
