# テンプレートの使い方

- [AGENTS.md](AGENTS.md)：対象プロジェクトのルートへ配置する入口。リンクは**配置後のルート基準**。このテンプレートの保管場所では `.awf/` は存在しない。
- [task-status.md](task-status.md)：必要な作業だけでコピーする状態表示例。会話やIssueで同等の情報を示す場合、ファイル作成は不要。

入口から参照するCoreは[Codex Adapter](../adapters/codex/README.md)の配置手順で `.awf/core/` に置く。別の場所を使う場合はリンクを調整する。状態テンプレートの山括弧内は説明なので、実作業では置き換える。使わない任意項目は削除してよい。

完了条件・権限・承認者などが依頼文や既存文書で分かるなら再記入しない。リンクだけでよい。テンプレートは機械可読スキーマや追加のCore要件ではない。
