# Task Status

- objective: <達成したいこと。既存の依頼への参照でもよい>
- status: working
- current_focus: <現在取り組んでいること>
- decisions: <重要判断と理由。まだなければ「なし」>
- evidence: <実行した検証の対象・結果・ログや出典の参照。未実施なら「未実施」>
- remaining: <不足事項・未確認事項。なければ「なし」>
- next_action: <次の作業、再開条件、または人間に求める判断>
- updated_at: <タイムゾーン付き日時>

## 必要な補足（任意）

- 完了条件・成果物: <依頼や受入基準への参照>
- 境界・承認: <許可範囲、禁止操作、必要な承認の対象・承認者・記録>
- 予算・中断条件: <タスクに合わせた上限、進展がない場合の対応>
- 引き継ぎ: <成果物の場所、最後の検証、再開時に確認すること>
