# Evidence

- id: evidence
- name: Traceable Evidence
- version: 0.1.0
- core_compatibility: AWF-SPEC-001 / 0.1.0-draft
- purpose: 主張と出典・実行結果の対応を追跡可能にする
- applies_to: 調査、文書、開発、運用
- preconditions: 確認する主張・完了条件が特定できる
- overrides: system-policy、runtime-controls、awf-core、domain-policy、repository-policy

## Rules

1. 重要な主張ごとに一次資料、成果物、観測結果のいずれかを対応付ける。
2. 文書は出典・該当箇所・版または公開日・確認日、実行は対象・コマンドまたは方法・結果を残す。日時や環境は結果を解釈するのに必要なら併記する。
3. 事実、解釈、提案、仮説を区別する。資料同士が矛盾する場合は対象版や条件を比べ、解消しなければ未確定とする。
4. 実行成功は、その検証が覆う範囲だけの根拠とする。未実施、失敗、対象外を明示し、必要な根拠が欠ければ完了にしない。
5. 機密情報や全文ログを無条件に保存せず、安全な要約と参照で足りるようにする。

## Verification

完了条件から根拠へ辿り、参照先が存在し、主張を実際に支持しているか確認する。リンクの存在確認は内容の正しさの証明ではない。

負担と評価：意思決定に影響する主張に限定し、出典不明・未検証事項の報告漏れを振り返る。
