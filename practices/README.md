# Practiceカタログ

Practiceは選択制。Coreの原則を具体的な方法で補助し、選ばなくてもCoreは有効です。作業に合わなければ外し、選択と理由を依頼や状態に短く示します。

| ID | 使う場面 | 前提 |
| --- | --- | --- |
| [security](security.md) | 外部作用、秘密情報、権限の確認が必要 | 対象・許可範囲を特定できる |
| [evidence](evidence.md) | 出典・実行結果を追跡したい | 確認する主張と情報源がある |
| [tdd](tdd.md) | 振る舞いを変える開発 | 実行可能なテスト環境がある |
| [pre-commit](pre-commit.md) | Git変更の早期チェック | Gitとプロジェクトの検査コマンドがある |
| [context-management](context-management.md) | 長時間作業・再開 | 人間も参照できる状態の置き場所がある |

各文書の `overrides` は**優先して遵守する上位の制約**を表し、上位ポリシーを無効化しません。Coreと競合するPracticeは採用せず、理由を示します。バージョンは本配布版に揃え、対応Coreと独立した改訂番号を各文書に記します。YAMLパーサーや自動選択機能は必要ありません。

追加時は目的、適用条件、前提、規則、検証方法、優先制約を記載します。防ぐ失敗、測りたい効果、追加負担を説明し、Coreを変更せず適用例で試します。[運用方針](../docs/maintenance.md)も参照してください。
